   Walking every transition:

   • A → B (git pack-refs): the watched loose file is deleted → Cargo detects deletion and re-runs; the next build computes state B.
   • B → C (commit on packed branch): new loose file created under the watched <base>/refs/heads directory → re-runs.

   • B → A (packed entry removed while no loose file exists): packed-refs content/file change → re-runs; falls back to state D first if the file is removed
     entirely.
   • D → A (first commit on unborn branch): new loose file created under watched <base>/refs/heads → re-runs.

   • HEAD = refs/heads/topic in a linked worktree: the common dir holds the loose ref (common_dir/refs/heads/topic), so that base returns the precise file;
     the worktree git dir falls back to git_dir/refs (over-trigger). No under-trigger.

   • Cargo recursively fingerprints the watched directory; it does not walk sibling directories. A git fetch that only updates refs/remotes/ will not trigger
