## Exact activation path required

For the shim to intercept a given agent command, **all** of the following must hold:
1. `scripts/install-cargo-shim` was run at least once on that machine/user account (manual, not automated anywhere).
2. That write went to the `.zshenv` resolved at install time (respecting `$ZDOTDIR` if set then — a later `ZDOTDIR` change would silently orphan the guard).
3. The agent's command-execution shell is `zsh` (any invocation mode — login, non-login, interactive, non-interactive — since `.zshenv` is sourced unconditionally by zsh, unless invoked with `-f`/no-rcs).
4. 5. `cargo` is invoked bare (not via absolute path, `rustup run ... cargo`, `cargo +toolchain` past the parser's coverage, or `--manifest-path`/`-C` into another repo) — all documented residuals.
