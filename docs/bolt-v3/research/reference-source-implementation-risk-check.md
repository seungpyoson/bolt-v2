# Reference Source Implementation Risk Check

## Scope

This note records the pre-implementation checks for the current reference-source handoff. It must not contain secrets, raw endpoints, raw reports, or credential values.

Provider names in this note are evidence from the handoff plan, not core architecture. Runtime source selection, comparator policy, and thresholds must be TOML-owned, while provider-specific provenance stays at provider edges.

## Stop Conditions

- Stop implementation if the configured boundary provider cannot supply its required provenance fields.
- Stop implementation if runtime credentials are not available through AWS SSM via the Rust SDK.
- Stop implementation if a provider requires environment-variable, local-file, 1Password, AWS CLI, or Python runtime fallback.
- Stop implementation if `ReferenceQuote` cannot be kept separate from boundary `price_to_beat` binding.
