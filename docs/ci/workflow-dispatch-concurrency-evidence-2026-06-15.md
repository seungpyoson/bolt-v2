Answer to "why ~8 dispatch re-runs/branch": the recent dispatch lane is acting
as an agent/operator exact-head PR verification loop for high-churn PRs. It is
not main, tag, or deploy activity. The lane still has a valid fallback purpose
for oversized PRs where GitHub does not deliver normal pull-request CI, but the
observed recent concentration is repeated branch-head verification during PR
iteration.

Reduction in this slice: repeated same-ref manual full-CI dispatches now cancel
older in-progress runs automatically through the existing `{ref}-full-ci`
concurrency group. This reduces obsolete overlap without weakening the manual
full-CI lane itself.

## Policy Change

Before:

```yaml
cancel-in-progress: >-
  ${{ github.event_name == 'pull_request'
      && github.event.pull_request.draft == true
      && contains(fromJSON('["opened","synchronize","reopened","converted_to_draft"]'), github.event.action) }}
```

After:

```yaml
cancel-in-progress: >-
  ${{ github.event_name == 'pull_request'
      && github.event.pull_request.draft == true
      && contains(fromJSON('["opened","synchronize","reopened","converted_to_draft"]'), github.event.action)
      || github.event_name == 'workflow_dispatch' }}
```

The concurrency group is unchanged:

- deferred draft PRs: `pr-{number}-deferred`
- full PR CI: `pr-{number}-full`
- manual dispatch full CI: `{ref}-full-ci`
- all other non-PR/non-dispatch runs: `{ref}-{sha}`

## Unaffected Flow Proof

The `cancel-in-progress` expression contains no `push`, no `refs/tags`, and no
`startsWith(github.ref, ...)` branch. Pushes, tag pushes, and deploy-triggering
tag flows therefore keep the non-PR fallback group and do not opt into workflow
cancellation.

Static guards:

- `scripts/verify_ci_workflow_hygiene.py` now requires
  `workflow_dispatch` cancellation for full-CI dispatch runs.
- The same verifier rejects `push`, tag, or deploy cancellation terms in
  `cancel-in-progress`.
- `scripts/test_verify_ci_workflow_hygiene.py` has regression checks for
  missing dispatch cancellation and accidental push/tag cancellation.
