# Archive Directory

This directory preserves historical/audit material for the
`023-nt-research-analytics-platform` planning package. It is not live authority
and it is not a fourth implementation project.

Live cross-project authority lives in `../reference/`:

- `../reference/evidence.md`
- `../reference/data-model.md`
- `../reference/contracts.md`

If an archive file disagrees with `../reference/` or a numbered project doc,
the live reference/project doc wins unless a future explicit evidence update
promotes the archived content back into authority.

## Archived Files

- `analysis.md`: review findings and consistency-check history.
- `cost-model.md`: cost baseline and pricing-provenance snapshots.
- `fidelity-matrix.md`: candidate source/fidelity research snapshot.
- `github-issues.md`: staged issue payload drafts; no mutation authority.
- `issue-audit.md`: issue-search command trail and due-diligence record.
- `open-questions.md`: answered/deferred decision prompts and handoff history.
- `requirements-checklist.md`: checklist history.
- `research.md`: source research and prior-art notes.
