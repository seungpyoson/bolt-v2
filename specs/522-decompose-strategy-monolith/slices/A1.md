# Slice A1 — extract OutcomeSide-free pure math + consolidate numeric primitives

**Epic**: #522 | **Spec**: `../spec.md` | **Plan**: `../plan.md` | **Class**: behavior-preserving move (pure-logic)

> Revised after codex adversarial review (2026-06-02): `OutcomeSide` is a cross-cutting
> domain type (93 refs: position/pending state, fee/book/instrument selection), not
> signal math, and it duplicates `bolt_v3_market_families::…::UpdownOutcomeSide`
> (findings-doc #13). It and the two side-using fns are therefore **deferred to A2**,
> which homes the side type in the market-family layer. A1 stays OutcomeSide-free so it
> introduces no cross-cutting coupling or re-export drift.

## Goal

Move the taker's **OutcomeSide-free** pure math into an intended **shared** module the
#488 maker can reuse, and consolidate the generic numeric primitives that math depends
on into the existing shared `bolt_v3_numeric`. No logic change. No new path.

## Verified facts (current-main `2938bc6f`, re-confirm at slice HEAD)

- Target functions are private free functions (`fn`); a cross-file grep for their names
  matches only **evidence field names**, not the functions → **no external callers**.
  Movement needs only in-file `use` imports, not external re-exports.
- Their external deps already live in shared `bolt_v3_numeric`: `ZERO_F64`, `UNIT_F64`,
  `POWER_OF_TWO`, `is_positive_finite`, `sanitize_probability`.
- Generic primitives used widely in the strategy but **nowhere outside it**:
  `clamp_probability`(10), `is_non_negative_finite`(6), `sanitize_non_negative`,
  `BPS_DENOMINATOR`(14), `MIDPOINT_DIVISOR_F64`(3), `QUADRATIC_RISK_DIVISOR`(2).

## Moves

### Target 1 — `src/bolt_v3_numeric.rs` (existing shared) gains generic primitives
- fns: `clamp_probability` (6879), `is_non_negative_finite` (6875), `sanitize_non_negative` (7141)
- consts: `BPS_DENOMINATOR` (6817), `MIDPOINT_DIVISOR_F64` (6818), `QUADRATIC_RISK_DIVISOR` (6819)
- Rationale: venue/strategy-agnostic primitives belong with the existing
  `ZERO_F64`/`is_positive_finite`/`sanitize_probability` — single source of truth
  ([AGENTS.md#repo-rule-no-dual-paths](../../../AGENTS.md#repo-rule-no-dual-paths)).

### Target 2 — `src/bolt_v3_taker_signal.rs` (NEW shared) gains OutcomeSide-free math
- input structs: `UncertaintyBandInputs` (7009), `ThetaScalerInputs` (7034), `RobustSizingInputs` (7110)
- fns: `price_agreement_corr` (6913), `price_gap_probability` (6922),
  `uncertainty_band_probability` (7017), `compute_theta_scaler` (7041),
  `choose_robust_size` (7119)
- imports `bolt_v3_numeric` for the primitives above.
- Boundary stays agnostic per the spec-023 contract: typed-in/typed-out; no imports of
  strategy archetypes, providers, evidence, admission, or market families.

### Strategy file (`src/strategies/binary_oracle_edge_taker.rs`)

  `use crate::bolt_v3_taker_signal::{…}` so in-file call sites resolve unchanged.
