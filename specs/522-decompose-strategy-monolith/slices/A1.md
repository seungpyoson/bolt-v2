# Slice A1 — extract pure taker decision/EV/sizing math

**Epic**: #522 | **Spec**: `../spec.md` | **Plan**: `../plan.md` | **Class**: behavior-preserving move (pure-logic)

## Goal

Move the taker's pure decision/EV/sizing math out of the 18k strategy file into an
intended **shared** module the #488 maker can reuse, and consolidate the generic
numeric primitives that math depends on into the existing shared `bolt_v3_numeric`.
No logic change. No new path.

## Verified facts (current-main `2938bc6f`, re-confirm at slice HEAD)

- All target functions are private free functions (`fn`, not `pub fn`); a cross-file
  grep for their names matches only **evidence field names** (e.g. `worst_case_ev_bps`),
  not the functions — so they have **no external callers**. Movement needs only
  in-file `use` imports, not external re-exports.
- Their external dependencies already live in shared `bolt_v3_numeric`:
  `ZERO_F64`, `UNIT_F64`, `POWER_OF_TWO`, `is_positive_finite`, `sanitize_probability`.
- Generic primitives used widely in the strategy but **nowhere outside it**:
  `clamp_probability`(10), `is_non_negative_finite`(6), `sanitize_non_negative`,
  `BPS_DENOMINATOR`(14), `MIDPOINT_DIVISOR_F64`(3), `QUADRATIC_RISK_DIVISOR`(2).

## Moves

### Target 1 — `src/bolt_v3_numeric.rs` (existing shared module) gains the generic primitives
- fns: `clamp_probability` (6879), `is_non_negative_finite` (6875), `sanitize_non_negative` (7141)
- consts: `BPS_DENOMINATOR` (6817), `MIDPOINT_DIVISOR_F64` (6818), `QUADRATIC_RISK_DIVISOR` (6819)
- Rationale: these are venue/strategy-agnostic numeric primitives; consolidating them
  with the existing `ZERO_F64`/`is_positive_finite`/`sanitize_probability` removes a
  split-brain numeric surface (single source of truth, CLAUDE.md rule #6).

### Target 2 — `src/bolt_v3_taker_signal.rs` (NEW shared module) gains the decision math
- enum: `OutcomeSide` (6883) + `outcome_side_evidence_label` (6889)
- input structs: `UncertaintyBandInputs` (7009), `WorstCaseEvInputs` (7026),
  `ThetaScalerInputs` (7034), `SideSelectionInputs` (7084), `RobustSizingInputs` (7110)
- fns: `price_agreement_corr` (6913), `price_gap_probability` (6922),
  `uncertainty_band_probability` (7017), `compute_theta_scaler` (7041),
  `compute_worst_case_ev_bps` (7056), `choose_entry_side` (7091),
  `choose_robust_size` (7119)
- imports `bolt_v3_numeric::*` for primitives above.
- Module boundary stays agnostic per the spec-023 contract: typed-in/typed-out; no
  imports of strategy archetypes, providers, evidence, or admission.

### Strategy file (`src/strategies/binary_oracle_edge_taker.rs`)
- Delete the moved items; add `use crate::bolt_v3_numeric::{...}` and
  `use crate::bolt_v3_taker_signal::{...}` so the ~30 in-file call sites resolve
  unchanged. No call-site edits beyond the imports.
- Register `pub mod bolt_v3_taker_signal;` in `src/lib.rs`.

### Tests
- Relocate the unit tests that exercise the moved units (e.g. `compute_worst_case_ev_bps_*`,
  `choose_entry_side_*`, `choose_robust_size_*`, `uncertainty_band_*`, `theta_scaler_*`,
  `price_gap_*`, `price_agreement_*`, and the numeric-primitive tests) into the
  `#[cfg(test)]` block of their new home module. This is most of the line reduction.
