# Slice A6 — exposure / recovery state machine -> `exposure.rs`

**Epic**: #522 | **Spec**: `../spec.md` | **Plan**: `../plan.md` |
**Class**: behavior-preserving strategy-internal move | **Branch**:
`feat/522-a6-exposure`

## Scope

Move the strategy's exposure, position, and recovery state machine out of
`src/strategies/binary_oracle_edge_taker/mod.rs` into
`src/strategies/binary_oracle_edge_taker/exposure.rs`. The move is strategy-internal:
`mod.rs` keeps orchestration, order construction, and caller methods, while `exposure.rs`
owns the state structs, transition enums, support predicates, and forced-flat predicate
evaluation.

No runtime logic changes. The only code-surface changes are:

- `mod exposure;` plus a private `use self::exposure::{...}` in `mod.rs`
- `pub(super)` visibility for moved items, fields, and methods used by `mod.rs`
- one characterization test added in the existing `#[cfg(test)] mod tests`

## Characterization

Added test:
`exposure_exit_pending_terminal_with_residual_position_restores_managed_state`.

It pins the A6-owned terminal transition where an exit receives a terminal event after a
fill while a residual position is still observed. The expected behavior is that
`ExitPendingState::into_state_after_exit_update` restores `ExposureState::Managed` with
the original position id and `ManagedPositionOrigin::StrategyEntry`, instead of flattening
the strategy.

Wrong-control RED proof:

```text
RUST_VERIFICATION_ROOT_BASE='<ALTERNATE_VERIFICATION_ROOT>' cargo test exposure_exit_pending_terminal_with_residual_position_restores_managed_state --lib
```

With a temporary `RecoveryBootstrap` expectation, the test failed as expected:
`left: StrategyEntry`, `right: RecoveryBootstrap`.

Restored GREEN proof with the checked-in `StrategyEntry` expectation passed:
`1 passed; 553 filtered out`.
