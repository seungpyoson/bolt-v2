# Slice A7 — source-proof / replay / evidence derivation -> `source_proof.rs`

**Epic**: #522 | **Spec**: `../spec.md` | **Plan**: `../plan.md` |
**Class**: behavior-preserving strategy-local move | **Branch**:
`feat/522-a7-source-proof`

## Scope

Move the strategy's entry-decision source-proof and replay helpers out of
`src/strategies/binary_oracle_edge_taker/mod.rs` into
`src/strategies/binary_oracle_edge_taker/source_proof.rs`.

No runtime logic changes. The intended code-surface changes are:

- `mod source_proof;` in `mod.rs`
- `pub use self::source_proof::{...}` only for the existing source API already used by
  `src/bolt_v3_operator_artifacts.rs` and the `selection` submodule
- one characterization test for reference-proof derivation
