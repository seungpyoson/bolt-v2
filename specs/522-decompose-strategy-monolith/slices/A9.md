# Slice A9 - admission-request construction -> `bolt_v3_submit_admission.rs`

**Epic**: #522 | **Spec**: `../spec.md` | **Plan**: `../plan.md` |
**Class**: shared execution/admission move | **Branch**:
`feat/522-a9-admission`

## Scope

Move submit-admission request construction and valuation out of
`src/strategies/binary_oracle_edge_taker/mod.rs` into
`src/bolt_v3_submit_admission.rs`.

This slice is the rule-#9 boundary for admission mechanics. Strategy code may provide
strategy-local context, but the shared admission module must own the request shape and
valuation rules.

No behavior change is intended. The strategy wrapper remains responsible only for
supplying strategy context:

- execution client id from strategy config
- lifecycle policy
- cached instrument/quote context only for order shapes that need it
- max fee lookup for the compiled order price
- managed-position context for risk-reducing exits

## Moved Responsibility

Shared admission now owns:

- order quantity parsing for admission requests
- compiled order price selection and parsing
- base-quantity notional valuation
- quote-quantity settlement notional valuation
- inverse quote-quantity fail-closed fallback
- market-style structural price-ceiling valuation
- fee-inclusive admission notional scaling
- order-intent to submit-intent mapping
- risk-reducing exit proof construction from supplied position context
- clearing order-intent canary-proof claims before submit admission

## New Shared API

Types added to `src/bolt_v3_submit_admission.rs`:

- `BoltV3SubmitAdmissionRequestInput`
- `BoltV3RiskReducingExitPositionInput`

Function added to `src/bolt_v3_submit_admission.rs`:

- `build_submit_admission_request_from_order`

## Stays In Strategy

- `BinaryOracleEdgeTaker` and actor orchestration.
- `submit_order_with_decision_evidence` and the actual NT submit call.
- Strategy cache access for instrument and quote context.
- Strategy-local fee provider lookup.
- Strategy-managed position lookup for exit proof inputs.
- Submit-admission state mutation and gate invocation.

## Test-Only Duplicate

The test helper `submit_admission_request_from_order_for_client` keeps its existing
base-limit guardrails, then delegates request construction to
`build_submit_admission_request_from_order`. It no longer duplicates the request
mapping logic.
